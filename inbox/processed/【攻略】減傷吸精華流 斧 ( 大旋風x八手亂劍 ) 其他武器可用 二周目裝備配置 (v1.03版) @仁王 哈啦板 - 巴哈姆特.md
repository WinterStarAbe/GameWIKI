# (3) 【攻略】減傷吸精華流 斧 ( 大旋風x八手亂劍 ) 其他武器可用 二周目裝備配置 (v1.03版) @仁王 哈啦板 - 巴哈姆特

大家好，我是ICE

  

減傷吸精華流，裝備配置 (V1.03版)，減傷被削弱做部分調整

低周目大概都可以硬壓過去。

  

地獄武技就請刷到武器→練滿愛用度提升學洗地獄武技

推薦琢技【大旋風→勝姿猛衝】或是【其他武器武技+轉心取消】

裝備打法，僅供參考，可自行調整

其他武器武技可自行研究。

  

若要看【圖片】部分，請參考影片。

  

《文章部分：表格表示》

  
※簡述重點

1.武器，可利用改造功能搭配能力值

2.加工功能，吸取精華+減傷為主

3.核心招式【大旋風】或是【武技→轉心取消】適用

4.四屬性從屬符、招屬符、可自行調整、全防具通用四屬符商店有賣

5.琢技連段每一層提高6%傷害，最多6層，

※提高技點數僅只有提高基礎第0層琢技傷害

6.精力條回復力方式，利用守護靈技壩體效果回復耐力，或是開場吃鬼燈果實(消耗品)
