※簡述重點

1.武器，可利用改造功能搭配能力值

2.加工功能，可以固定普通技能(箭矢無消耗)

3.武士型態為重甲，可以敏B，武器挑喜歡就好

4.操作手冊01《御神水 → 修羅 → 拳力 → 獄風 → 獄水 → 獄炎 → 獄雷》

  操作手冊02《御神水 → 修羅 → 拳力 → 獄風 → 獄水 → 獄炎 → 獄雷 →

切換武士 → 箭矢火藥 → 拉弓》

※注意事項【空手才吃拳力符效果】
