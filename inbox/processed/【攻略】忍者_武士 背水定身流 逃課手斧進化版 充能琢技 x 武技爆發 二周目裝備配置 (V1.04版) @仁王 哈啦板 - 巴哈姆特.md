# (3) 【攻略】忍者/武士 背水定身流 逃課手斧進化版 充能琢技 x 武技爆發 二周目裝備配置 (V1.04版) @仁王 哈啦板 - 巴哈姆特

大家好，我是ICE

  

分享一套，忍者控制累積琢技，武士爆發武技

逃課武器，手斧搭配背水，形成風險較低的打法，可以利用背水提升傷害

打空精力後，搭配影縫，切換武士爆發一波琢技玩法

連段順利，可以讓怪保持空精狀態到開常闇(其他武器都可自行研究琢技連段)

背水定身流，不綁武器配置，堅忍A敏捷A

若要看【圖片】部分，請參考影片。

  

※此套裝需要忍者飾品刷出【影縫上限+1】

  

※簡述重點

1.武器，可利用改造功能搭配能力值

2.加工功能，忍者防具【堅忍度】、吸取精華+減傷為主

3.忍者武器推薦 手斧，其他武器用法可以留言分享

4.武士武技推件 斧，其他武器用法可以留言分享

5.陰陽術部分可自行調整
